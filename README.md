## The joke

> My cat knocked my phone off the table, watched it fall, then looked at me like it was my fault for not catching it.

## How it works

`main.ts` writes that single line (115 characters) to `/output/entry.txt`, validating first that it is 1–200 characters, a single line, and not only whitespace, then reading it back to confirm the file holds exactly the validated text.

## Run

```sh
node main.ts
cat /output/entry.txt
```

Requires Node 22.18 or later.
